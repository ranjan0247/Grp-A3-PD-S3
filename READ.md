# Simple Line Editor

A command-line text editor built in C that operates on specific line numbers.

*   RANJAN

## Features Implemented
We implemented the following core features:
*   **Insert a line:** Add text at a specific index.
*   **Delete a line:** Remove text at a specific index.
*   **Display the document:** View the current state of the text document.

## How to Compile
To compile the source code using `gcc`, open your terminal in the project directory and run:
`gcc editor.c -o editor`

## How to Run
Once compiled, run the executable with the following command:
`./editor`
